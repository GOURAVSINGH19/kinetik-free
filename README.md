# Kinetik

Free, open source React components with smooth micro-interactions, built with Tailwind CSS and Motion. Copy the code into your project and make it yours.

Live previews, props and install commands: https://kinetikui.vercel.app

## Components

- accordion
- alert
- aspect-ratio
- badge
- button
- click-spark
- collapsible
- dropdown
- file-attachment
- folder
- goo-search
- icons
- menubar
- organic-growth
- popover
- scroll-area
- segmented-nav
- separator
- simple-search
- sliding-tabs
- tabs

## Usage

Copy a component folder into your project's `components/` directory, plus `lib/utils.ts`
(and `styles/tokens.css` if the component uses the Kinetik tokens). Imports use the `@/` alias.

## Pro

More components are available in Kinetik Pro and are not part of this repo.
